🛒 E-Commerce Mobile Application

This project is a full-featured e-commerce mobile application designed to provide users with a smooth and secure online shopping experience. The application follows a modern client–server architecture, with a Flutter-based mobile frontend and a MERN stack backend.

The backend is built using Node.js and Express.js, with MongoDB as the database, providing scalable and efficient RESTful APIs for handling users, products, carts, orders, and payments. Authentication and authorization are implemented using JWT, ensuring secure access to protected resources.

The mobile frontend is developed using Flutter, delivering a fast, responsive, and cross-platform user experience on both Android and iOS.

✨ Key Features

User authentication and authorization

Product listing with categories and search

Shopping cart and order management

Secure checkout and payment integration

Order tracking and history

Admin functionality for managing products and orders

🛠️ Tech Stack

Frontend: Flutter

Backend: Node.js, Express.js

Database: MongoDB (Mongoose)

Authentication: JWT

API Style: RESTful APIs

This project is structured to be scalable, maintainable, and easy to extend, making it suitable for real-world e-commerce use cases and future enhancements.
